# User Stories

## 1. Shannon-Fano Encoding

### User Story
Як користувач,  
я хочу мати можливість кодувати текст за допомогою алгоритму Шеннона-Фано,  
щоб ефективно стискати дані.

### Acceptance Criteria
- Користувач може ввести текст
- Система виконує кодування методом Шеннона-Фано
- Результат відображається у вигляді бінарного коду
- Відображаються коди для кожного символу

---

## 2. Huffman Encoding

### User Story
Як користувач,  
я хочу мати можливість кодувати текст за допомогою алгоритму Хаффмана,  
щоб порівнювати ефективність методів стиснення.

### Acceptance Criteria
- Користувач може ввести текст
- Система виконує кодування методом Хаффмана
- Генерується дерево Хаффмана
- Відображається результат кодування

## 3. Decoding

## 5. Error Detection

### User Story
Як користувач,  
я хочу мати можливість виявляти помилки,  
щоб визначати пошкоджені дані.

### Acceptance Criteria

- Визначається наявність помилки

---

## 6. Error Correction

### User Story
Як користувач,  
я хочу мати можливість виправляти одиничну помилку,  
щоб відновлювати правильні дані.

### Acceptance Criteria
- Визначається позиція помилки
- Виконується виправлення біта
- Дані відновлюються
